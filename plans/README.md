## 2026-07-03 audit round (plans 008–013): surfaced but not selected

Vetted findings presented to the maintainer on 2026-07-03; the maintainer chose
not to plan them this round. They are NOT rejected on the merits — a future
round may pick them up. Do not re-audit; re-present.

- **Duplicated, untested green/plate access classifier**: `scripts/fetch-mvum-area.mjs:58` (`classify`) and `scripts/build-area-routes.mjs:1196` (`segAccess`) encode the identical rule independently, so the overview map and route badges can silently diverge on legal access; zero tests. Fix = one shared classifier + table-driven characterization tests (M, MED risk via regen diff).
- **MVUM pipeline bridges real gaps**: `build-area-routes.mjs:1205` still uses the older single-path `stitch`; the gap-aware `stitchParts` (275 m split, per-part `<trkseg>`) exists byte-identically in the BLM/Angeles builders but was never back-ported. Possible phantom straight lines + inflated `distanceMiles` on disjoint multi-segment USFS routes (e.g. the 2E20.x set). Fix requires a network regen + committed-data diff review (M, MED).
- **Pipeline fragility**: no fetch retry, no per-route error isolation; a transient federal-GIS 5xx aborts a whole regen and can leave `public/gpx/` updated while `lib/routes/*.generated.ts` is stale (`build-area-routes.mjs:1189-1190, 1354, 1403-1415`) (S–M, LOW).
- **No response security headers + one unescaped tooltip**: no CSP/`nosniff`/`Referrer-Policy` on the Cloudflare static assets (a `public/_headers` file would do it); `components/OverviewMap.tsx:95` binds `a.name` to a Leaflet tooltip unescaped while sibling `AreaMap.tsx:132` escapes. Data is maintainer-authored, so hardening only (S, LOW value).
- **Toolchain alignment**: `@types/node ^20` vs Node 24 in CI/runtime; pending patch bumps (Next 16.2.10, React 19.2.7, Tailwind 4.3.2); no `engines` field or `.nvmrc` (S, LOW).
- **Overview GeoJSON density** (investigate-grade): `big-bear-mvum.geojson` is 948 KB raw / 47k vertices for a ~560 px Leaflet frame (`AreaMap.tsx:84-90`). Verify the brotli over-the-wire size before investing in a simplified `*-overview.geojson` variant.
- **Direction candidates** (grounded in PRODUCT.md, not planned): statewide filterable route index (difficulty × access × distance over the existing registry — the strongest one; the maintainer's own impeccable critique flagged it); "rideable now" seasonal surface from `bestSeason` (needs free-text normalization; honesty constraint); closure surfacing at home/hero level via a structured `closure` field (plus the BLM `closuresUrl` points at the office homepage while labeled "alerts and current closures"); printable/offline area sheet (LOW confidence, print stylesheet first).
